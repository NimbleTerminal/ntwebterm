# Multilingual renderer checks

This suite verifies representative multilingual text in real Chrome across
Canvas2D, WebGL2 and WebGPU. It runs 18 cases: font sizes 14 and 20 px, DPR 1,
1.25 and 2, and all three renderers.

The corpus covers accented Latin, Vietnamese, Greek, Cyrillic, Chinese,
Japanese, Korean, Devanagari, Bengali, Tamil, Thai, Khmer, Hebrew, Arabic,
mixed-direction text, combining marks, emoji and wide-character spacing. One
row also composites multilingual text over a Kitty image. The corpus is a
representative regression suite, not a claim to cover every language or every
regional CJK glyph variant.

Each case checks:

- Exact logical text round-trips through Ghostty's buffer.
- CJK wide cells and spacer cells have the expected widths.
- CJK, combining-mark and Hebrew selections return the original text.
- Every DOM font probe resolves only to bundled fonts, with no host fallback.
- Cell metrics and canvas dimensions match the golden.
- Screenshots match the golden within a per-channel threshold of 32 and a
  changed-pixel limit of 0.1%.

Arabic words are shaped as complete contextual runs, including lam–alef and
combining marks, then fitted and sliced into their terminal cells. The Arabic
and mixed-direction rows therefore exercise joining as well as logical text
preservation in every backend.

## Run

Start Vite in one terminal:

```bash
bun run dev
```

Playwright is an optional external tool for this suite, matching the existing
renderer-check scripts. For a local ignored installation:

```bash
npm install --prefix .vite/multilingual-tools playwright
export PLAYWRIGHT_MODULE="$PWD/.vite/multilingual-tools/node_modules/playwright/index.mjs"
bun run test:multilingual
```

Alternatively, set `PLAYWRIGHT_MODULE` to the `index.mjs` of an existing
Playwright installation. Chrome must be installed; the runner uses Playwright's
`channel: 'chrome'`.

To inspect one page manually, open:

```text
http://localhost:8000/demo/multilingual-renderer-check.html?renderer=canvas2d&size=14
```

## Update goldens

Review the current captures in `.vite/multilingual/`, then regenerate the
approved images and metadata only for an intentional rendering or corpus
change:

```bash
bun run test:multilingual:update
```

Inspect the resulting PNGs before accepting them. The checked-in goldens were
generated on macOS arm64 with Chrome 157. The assertion rejects a different
platform/architecture rather than silently comparing unrelated rasterizers.

## Fonts

`demo/fonts/` contains small WOFF2 subsets generated by Google Fonts from the
exact corpus, together with their SIL Open Font Licenses. They make this test
deterministic; they are not complete production fonts and must not be used as
general multilingual font bundles.

After changing `demo/multilingual-corpus.js`, refresh the subsets and review
new goldens:

```bash
bun run fonts:multilingual
bun run test:multilingual:update
```

The fetch script contacts Google Fonts for the subsets and the `google/fonts`
repository for the corresponding licenses. Files already checked in do not
require network access during browser tests.
